# SQL Retail Sales Analysis Project

## Project Overview
This is my first SQL project, created to practice SQL queries and analyze retail sales data. The project focuses on extracting meaningful insights from sales transactions using SQL.

## Objectives
- Analyze retail sales data.
- Identify sales transactions based on specific conditions.
- Calculate total sales and transaction counts.
- Analyze customer purchasing behavior across different categories.
- Explore sales patterns using SQL queries.

## Tools Used
- **Database:** PostgreSQL
- **SQL Tool:** pgAdmin 4

## SQL Concepts Used
- SELECT and WHERE
- ORDER BY and GROUP BY
- Aggregate functions (SUM, COUNT, AVG)
- DISTINCT
- Filtering with AND and OR
- Date filtering
- HAVING clause
- Data analysis using SQL queries

## Key Analysis
- Identified high-value sales transactions.
- Analyzed transactions by gender and product category.
- Explored customer purchasing patterns.
- Practiced filtering sales by date, quantity, and total amount.

## Key Learnings
Through this project, I gained practical experience writing SQL queries, filtering and grouping data, using aggregate functions, and answering business-related questions from a retail sales dataset.
